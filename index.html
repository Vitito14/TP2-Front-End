Objetivo

Este proyecto tiene como finalidad comparar la calidad de generación de código HTML, CSS y JavaScript producido por distintos modelos de Inteligencia Artificial frente a un mismo Prompt.

La comparación incluye estructura HTML, diseño responsive, experiencia de usuario (UX), organización del código, accesibilidad y buenas prácticas de Front-End.
