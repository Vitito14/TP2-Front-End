# Descripción

Este proyecto tiene como objetivo analizar y comparar la capacidad de distintos modelos de Inteligencia Artificial para generar una Landing Page completa a partir de un mismo Prompt.

Para ello se utilizó exactamente el mismo requerimiento sobre dos modelos diferentes:

* ChatGPT
* Claude Sonnet 4.6 Max

Los resultados obtenidos fueron integrados dentro de un único sitio web que permite visualizar el Prompt original y navegar entre ambas implementaciones para facilitar su análisis.

---

# Objetivos

* Aplicar conceptos de Ingeniería de Prompt.
* Analizar la calidad del código generado por distintos modelos de IA.
* Comparar la organización del código HTML, CSS y JavaScript.
* Evaluar criterios de accesibilidad y diseño responsive.
* Aplicar buenas prácticas de Desarrollo Front End.
* Integrar diferentes implementaciones dentro de un único proyecto web.

---

# Prompt utilizado

El Prompt solicitado fue el siguiente:

> Generar una Landing Page moderna, responsive y completamente funcional utilizando únicamente HTML5, CSS3 y JavaScript, incluyendo navegación, Hero Section, About, Services, Testimonials, Contact Form y Footer.

El Prompt completo puede visualizarse desde la opción **Prompt Utilizado** disponible en la portada del proyecto.

# Conclusiones

La utilización de herramientas basadas en Inteligencia Artificial representa un importante apoyo para el desarrollo de interfaces web, permitiendo acelerar significativamente la generación de prototipos y aplicaciones.

Sin embargo, el resultado obtenido depende en gran medida de la calidad del Prompt utilizado, así como del criterio técnico del desarrollador encargado de revisar, adaptar y validar el código generado.

El presente trabajo demuestra que diferentes modelos de IA pueden producir soluciones funcionales para un mismo requerimiento, aunque presentan diferencias en cuanto a organización, estructura, estilo visual y enfoque de implementación.

En consecuencia, la Ingeniería de Prompt se convierte en una habilidad relevante dentro del proceso moderno de desarrollo de software, complementando los conocimientos tradicionales de programación y diseño de interfaces.
