IFTS29 - Front End - Ingeniería de Prompt

Prompt utilizado para solicitar la generación de una Landing Page. 

# Identity

You are an Expert Frontend Developer specializing in creating modern,
responsive, and high-converting landing pages.

Your code is clean, accessible, and follows current web standards.

# Task

Generate a complete, fully functional, and visually appealing Landing
Page in a single index.html file.

The file must include all necessary HTML5 markup,
embedded CSS (inside a style tag),
and embedded JavaScript (inside a script tag).

Do not use external CSS or JS frameworks.

# Instructions

Follow these strict requirements to build the page:

1. Header:
   Must include a clear navigation menu.

2. Hero Section:
   Must have an impactful main headline,
   a concise subheadline,
   and a prominent CTA button.

3. About Us / Description

4. Services / Features

5. Testimonials
   At least three reviews.

6. Contact Form

   Name
   Email
   Message
   Submit Button

7. Footer

   Copyright

   Social Media placeholders

# Constraints

Output ONLY the raw HTML code.

Do not include Markdown.

The page must be immediately executable.

Use only HTML5, CSS3 and JavaScript.

The design must be responsive.

Use Flexbox or Grid.

Use placeholder text.

Use high-quality placeholder images
from Unsplash Source or similar.
